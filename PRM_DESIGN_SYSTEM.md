# PRM Design System

## Visual Principles
- Fast, professional, premium, and keyboard-first.
- Light theme first with a strong blue primary accent.
- Consistent spacing, cards, and action grouping.
- Modern desktop ergonomics for 8–12 hour daily use.

## Shared Components
- Page header with title and subtitle.
- Action toolbar with core transaction actions.
- Card-based form sections for header and item entry.
- Structured summary panel for totals and status.
- Refined table styling with clear selection and alternating rows.

## Color Language
- Primary blue: #1D4ED8
- Success green: #0F766E
- Warning amber: #D97706
- Danger red: #DC2626
- Neutral slate: #0F172A / #F8FAFC
