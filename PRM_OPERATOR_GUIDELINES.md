# PRM Operator Guidelines

## Daily Usage
- Use the action toolbar for primary transaction actions.
- Keep the product search field focused for fast entry.
- Use Enter to move through the flow.
- Review totals in the fixed summary panel before save.

## Efficiency
- Minimize mouse travel by keeping primary actions in one toolbar.
- Prefer keyboard shortcuts for common actions.
- Maintain consistent habits across quotation, sales, purchase, and delivery workflows.
